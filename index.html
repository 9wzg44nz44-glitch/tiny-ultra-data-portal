How to use

  1. Run the TinySA Ultra, capture your sweep (touchscreen or PC software).
  2. Export as CSV from the analyzer or the PC app.
  3. Upload here with an experiment ID so files sort themselves.
  4. The file is committed to the repo under data/uploads/<experiment>-<timestamp>.csv — versioned, backed up, shareable with Dr. Hively.

CSV format: frequency (Hz), amplitude (dBm) per row, as exported by the TinySA. S2P: standard touchstone, any number of ports.
